These posters are no longer the catalog's artwork. Live cover art and banners
come from the AniList CDN (s4.anilist.co) or, on the MyAnimeList fallback
path, cdn.myanimelist.net.

They are still used for two things:
  1. the bundled offline sample library (lib/anime/offline.ts), which only
     answers when every live catalog source is unreachable;
  2. the fallback image a card shows if a remote poster fails to load.

Provenance: collected from visual-search results for layout prototyping; no
visible stock watermark was observed. `bleach-tybw.jpg` is an original
AI-generated placeholder.

No video clips ship with this repository. See docs/PREVIEW-ASSETS.md for how
to add a `/previews/<slug>.webm` hover loop.
